# Public Trust Verification

ARV Proof OSS keeps trust verification public and independently auditable.

An independent verifier must be able to determine whether a cryptographically valid proof is authorized, unofficial, suspended, revoked, expired, compromised, or outside the applicable authorization scope.

The public reference implementation is located under reference/typescript/arv/.

The public trust-verification surface does not distribute ARV private signing keys, managed trust-root operations, issuer onboarding infrastructure, managed official issuance, commercial policy engines, or private customer data.

Cryptographic integrity, provenance, governance authorization, official status, and material truth are separate determinations.
